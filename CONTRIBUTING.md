# Contributing

1. One agent per pull request.
2. Link to the vendor's own product page, not a review or affiliate page.
3. Describe what it produces and how you revise a result, in one or two plain sentences. No "best", "revolutionary" or other superlatives.
4. Add a row to the comparison table with the same columns.
5. If you work on the product you are adding, say so in the pull request.

Entries are removed when the product page goes offline or the agent mode is discontinued.
